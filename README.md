# 军藏思维计算仪 · 黑流树海

> 《明日方舟》集成战略「沉沦者的黑流树海」自然物增值推演工具。
> 输入你手头的自然物数量，帮你一眼看出**现在打哪种作战节点最赚**。

在线使用：**https://muguang264.github.io/Juncang-Thinking-Calculator/**

支持手机安装、离线使用。

---

## 这是什么

在黑流树海里，自然物（零件的一种）本身不能使用，只能卖钱，效果是让"估价"越滚越高。每种自然物对不同的行为加成不同：有的按招募次数加成，有的按作战次数加成，有的按获得零件数量加成。

打不同作战节点时，触发的招募 / 作战 / 零件次数不一样，所以**同样一套库存，打不同节点收益天差地别**。

这个工具就是帮你把这笔账算清楚：**当前库存下，哪个作战节点带来的增值最高**，并给出等效收藏品估算，方便你规划路线。

---

## 快速上手（3 步）

1. 打开网址（或安装到手机主屏）。
2. 在左侧「自然物库存」里，用 `+` / `-` 或直接输入数字，填上你当前持有的各种自然物数量。
3. 右侧「作战增值排序」会**实时**从高到低列出各作战节点的收益，排在第一位的就是当前最划算的。

数字全自动保存，下次打开还在。

## 功能说明

### 1. 自然物库存输入
- 五种自然物各一行：图标、名称、效果说明、数量调节。
- 点 `+` / `-` 每次精确加减 1；**按住不动约 2 秒后开始连续加减**，松手即停。
- 点数字框会自动全选，直接输入新数字即可覆盖。
- 输入空值按 0 处理；负数、小数会自动修正为合理整数。
- 底部「重置」：把所有自然物数量清零（**不会**动顶部的结局藏品勾选）。

### 2. 作战增值排序（核心）
- 五个作战节点按**增值从高到低实时排序**，柱子越长收益越高。
- **第一名**会高亮：名称变金色、带闪烁的 `▶`，下方显示 `+X%`（相对普通作战的增幅）。
- 如果普通作战增值为 0，增幅会显示 `+∞`。
- 每个节点下方给出「等效收藏品数量」估算；紧急作战、居民据点会额外标注括号值，表示**算上这局额外送的 1 个收藏品**后的数值。

### 3. 商店招募券净增值
- 在回声玉米那一行下方单独显示：**玉米数量 × 3 − 4**。
- 正数显示为暗金色（划算），负数显示为暗红色（不划算）。

### 4. 结局藏品勾选（顶部）
- 顶部有「沙盘α / 沙盘β / 怦然信标」三个勾选框，标记你这局对应的结局藏品。
- 状态会保存，登录后还会同步到云端。
- 右侧的圆形刷新按钮：只重置这三个勾选，不影响自然物数量。

### 5. 均藏对局收录（页面最底部）
- 记录你每一局拿到的收藏品数量，随时查看自己的"均藏"（平均收藏品产量）。
- 标题行实时显示当前均藏；点标题行可展开 / 收起。
- 每行填「对局说明 + 收藏品数量」，可添加、删除；均藏实时重算。
- 「清空全部对局」会二次确认，防止误删。

### 6. 折线图
- 用折线展示你每局收藏品数量变化，一眼看出趋势。
- 数量最高的那些局会标记为星形；另有一条虚线标出你的**均藏水平**，方便对比单局是高是低。

### 7. 云端同步（可选，跨设备）
- 用邮箱注册 / 登录后，对局记录和结局藏品勾选会存到云端。
- 换手机、换电脑，登录同一账号即可看到自己的数据。
- **不登录也能用**：数据只存本机，功能完全不受影响。

### 8. 安装到手机 & 离线使用
- 打开网址后，右下角会出现「安装到主屏幕」按钮，点一下即可装成手机 App，像原生应用一样全屏打开。
- 首次联网打开后会自动缓存，之后**断网也能打开和计算**（只有登录 / 云端同步需要联网）。
- 安装方法：
  - **安卓（Chrome / Edge）**：点右下角按钮，或浏览器菜单里的「安装应用」。
  - **苹果（用 Safari）**：点右下角按钮看指引，或「分享 → 添加到主屏幕」。
  - **电脑（Chrome / Edge）**：点地址栏右侧的安装图标。

## 计算口径说明

- **增值**：在你这套自然物库存下，打完某个作战节点，自然物带来的总估价提升。
- **等效收藏品**：增值 ÷ 10，四舍五入保留 1 位小数。
- **额外奖励**：紧急作战、居民据点会额外多给 1 个收藏品，界面上用括号单独标出。
- **商店招募券净增值**：玉米数量 × 3 − 4。

各自然物的加成方向：

| 自然物 | 效果 |
| --- | --- |
| 回声玉米 | 每次招募干员，估价 +3 |
| 霜晶树 | 每次作战后，估价 +4 |
| 血蕈 | 每次作战后，估价 +2 |
| 板藤 | 每次获得零件时，估价 +4 |
| 多生苔藓 | 每次获得零件时，估价 +1 |

> 数值与机制以游戏内实际为准；如版本更新导致数据变化，会尽快跟进。

## 常见问题

**数据会丢吗？**
不会。未登录时存在本机浏览器里；登录后同步到云端，换设备也能找回。清除浏览器数据会清掉本机未同步的记录。

**为什么排第一的有时会变？**
排序跟你填的自然物数量有关。玉米多了偏招募类节点，板藤 / 苔藓多了偏零件类节点，实时变化是正常的。

**装了手机 App 后断网能用吗？**
能。核心计算和图表都做了离线缓存；只有登录和云同步需要联网。

**点击 `+` 会不会一次加 2？**
不会，单次点击只加 1；要快速加就长按。

**计算结果的依据是什么？**
见上方「计算口径说明」。这是基于规则的推演估算，实际以游戏内为准。

<summary>进阶：自行部署 / 技术说明（点开）</summary>

- 纯前端单页，无构建步骤；核心计算逻辑内联在 `index.html`。
- 托管：把仓库根目录文件部署到任意静态站点（如 GitHub Pages）即可，入口为 `index.html`。
- PWA：`manifest.json` + `service-worker.js` + 图标文件；Service Worker 需 HTTPS。
- 云端同步使用 Supabase（需自建 `duiju_records` 表并配置 RLS）；未配置或 CDN 加载失败时自动降级为纯本地模式。
- 依赖（CDN）：Supabase JS `2.47.10`、Chart.js `4.4.7`。
- 更新需被缓存的内容后，把 `service-worker.js` 顶部的 `VERSION` 递增即可清理旧缓存。
- 图标可用 `make-icons.py` 由一张源图批量生成。
